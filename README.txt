CYBER STUDENT ACADEMY V3
========================
Complete local cyber-security student website.

FEATURES
- Student registration, login, logout
- SQLite database and salted PBKDF2 password hashing
- 13-topic learning roadmap and progress tracking
- Personal notes with save/delete
- Quiz attempts, points and leaderboard
- Achievements
- Password-strength checker
- Networking, Linux and Blue-Team references
- Safe-lab guidance
- Career and portfolio section
- Responsive cyber-themed UI

RUN
1. Open PowerShell inside this folder.
2. python -m pip install flask
3. python server.py
4. Open http://127.0.0.1:8000

Keep PowerShell open while using the website.
Use security skills only on systems you own or have explicit permission to test.
